使用流程

1

启动完整技术栈

克隆仓库后一条 just dev 拉起 API、worker、Web、PostgreSQL、Redis、RustFS 与 Mailpit。

2

发出第一条全栈请求

从真实请求开始跟做教程，每一章都对应可运行的命令与测试入口。

3

组合或移除参考业务

按所有权清单整块移除参考示例，Core 保持原样运行，业务边界有静态检查守护。

4

部署、备份与恢复

单机 compose 生产部署与降级验证，配合备份归档与独立环境恢复演练。

真实能力

以下能力均已交付，各自带有教程章节、自动化测试与门禁，不是计划项；逐项对照见 v1 覆盖与验收。

注册、登录与会话

事务化的注册与登录、会话失效与多端管理，对照 API 测试与真实浏览器旅程验证。

成员管理与最后 Owner

成员角色变更与去激活即时失效会话，最后 Owner 保护防止锁死组织。

密码重置与可靠邮件

注册与重置邮件在开发栈由 Mailpit 接收，生产切换真实 SMTP。

请求限流与保守回退

Redis 限流与保守回退：缓存不可用时服务照常响应，系统页展示真实状态。

Electron 桌面壳

同一套 Web 页面进入安全桌面壳，IPC 契约测试与桌面冒烟在 CI 运行。

单机生产部署

compose 生产栈与降级验证，公开教程覆盖从证书到回退的完整过程。

备份与恢复演练

备份归档不含秘密，在独立环境恢复后验证文档、附件与任务。

参考示例：个人知识库

一个可整块移除的参考业务，演示业务约束、并发与资源授权如何组合在 Core 之上；边界与移除步骤见 组合与移除参考业务。

第一篇 Markdown 文档

文档的增删改查与正文安全渲染。

标题搜索与安全预览

标题搜索、分页与不执行脚本的预览。

显式保存与版本冲突

宽屏双栏实时预览，窄屏页签；并发保存触发 409，冲突处理可理解。

共享知识库与权限继承

Reader/Editor 授权、回收与权限继承。

RustFS 附件

附件上传下载走真实对象存储、校验与浏览器 CORS。

文档导出与任务

ZIP 导出交给 PostgreSQL Jobs，失败可由管理员重试。

API Key 与资源权限

签发 API Key 读取其有权访问的知识文档，权限范围可验证。
