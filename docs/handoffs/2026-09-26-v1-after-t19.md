## 需要保留的实现约束

- 单企业部署；邮箱密码公开注册；知识库业务简单、可教学、可移除。Core 不反向依赖 Knowledge，所有权由 examples/knowledge-base/manifest.json 管理。
- Worker 在 Handler 执行时独立续租；续租失败先丢弃 Handler/事务，再有限时间写失败。不能把这段逻辑退化为暂停 Handler 等待 heartbeat。
- 导出是不可变请求时快照。对象与 ZIP 持久发布、lease fencing、受控重试和回收已有真实实现；不记录原始存储错误或签名 URL。
- Redis 缓存每次仍先查 PostgreSQL 的权限和准确版本；Redis 故障回源。限流保留本地已消耗预算，不信任任意 X-Forwarded-For。
- 密码重置原子更新凭据、消费 token、撤销全部旧 Sessions/其他重置并追加 Audit。登录发会话前重查已验证 hash，避免旧密码并发登录。
- 邮件 Job payload 只有 reset ID；短期材料使用独立加密 key/version。开发 key 保存在私有 `.secrets/development-mail-key`，不得提交或输出。SMTP 接受后仍可能重复同一链接；单次消费由事务保证。
- Telemetry 仅用于诊断：数据可能丢失，不能作为业务事实或授权依据。actor 来自认证成功点，trace context 独立存于 Job metadata。Domain 不依赖 OTel。
- OTLP/日志出口有界；SDK 0.33 metrics shutdown 固定等待最多 5 秒，开发脚本额外留 10 秒。不要假设设置更短 timeout 能取消底层工作。
- 当前观测 profile 用于本机教学：只支持本地 HTTP OTLP，Grafana 匿名只读；不是公共生产部署方案。Collector 以只读挂载和 DAC_READ_SEARCH 读取私有宿主机日志。
- 移除示例时保留 Telemetry、Core 测试、profile、通用看板与配置。T19 的导出 smoke 和教程属于 example；tempfile 现被 Core telemetry 测试使用，不再列为纯 example 依赖。
