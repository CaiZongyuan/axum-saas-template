# Rust 公共接入地图

这页面向正在编写自己业务模块的后端开发者。HTTP DTO 在 [API 参考](site:reference/api.md) 查阅；Rust 函数的完整签名和内部限制以链接源码为准。先完成 [新增后端模块](../guides/develop-module.md)，再按需要接入下表。

`saas_app` 提供 SaaS Core 与 HTTP 边界，`saas_platform` 提供配置和基础设施适配。业务模块调用这些公开能力；API 与 Worker 在应用侧显式组装。当前企业模型是单个 Organization，不支持把不同客户的数据放进同一数据库后自动隔离。

## HTTP 与身份

| 公开入口                                                                                                                                         | 调用上下文                                                  | 返回值或错误                                 | 责任与限制                                                                                | 受检查用法                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| [`compose_routes_with_options`](../../crates/app/src/lib.rs) / `CoreOptions`                                                                     | 应用启动：连接池、认证配置、业务 Router、合并 OpenAPI       | Axum `Router`                                | 提供 Core 路由、request_id、限流和统一 fallback；先完成业务 state，再 merge               | [第一阶段模块](../../examples/tutorial-tickets/preview.rs)、[HTTP 健康测试](../../crates/app/tests/health.rs) |
| [`BoundedJson`](../../crates/app/src/http.rs)、[`ApiQuery`](../../crates/app/src/http.rs)、[`ApiPath`](../../crates/app/src/http.rs)             | 经过 Core request_context 的 Handler；JSON extractor 放最后 | 反序列化后的 DTO；失败为公开 `Response`      | 只负责协议读取；长度和业务规则继续由 Domain 验证                                          | [身份 HTTP 测试](../../crates/app/tests/registration.rs)                                                      |
| [`require_session`](../../crates/app/src/modules/identity/mod.rs)                                                                                | 连接池、`AuthSettings`、请求头、`RequestId`、是否 mutation  | `Result<CurrentSession, Response>`           | mutation 校验 Origin/CSRF；显式 Authorization 不会退回 Cookie；写事务仍须重新锁定有效成员 | [Session HTTP 测试](../../crates/app/tests/sessions.rs)、[Session 接入](../tutorials/03-sessions.md)          |
| [`require_read`](../../crates/app/src/modules/api_keys/authentication.rs)                                                                        | 只读接口，额外传入业务注册的 scope                          | `Result<ReadActor, Response>`                | Bearer 存在时优先；检查凭据、成员和 scope 后，业务继续检查资源权限                        | [API Key HTTP 测试](../../crates/app/tests/api_keys.rs)、API Key 接入                                         |
| [`KeyScope`](../../crates/app/src/modules/api_keys/mod.rs)、[`core_scopes`](../../crates/app/src/modules/api_keys/mod.rs)                        | API 应用组装                                                | scope 声明 / Core scope 列表                 | 把业务只读 scope 添加到 CoreOptions；scope 不等于资源授权                                 | [API 组装点](../../apps/api/src/lib.rs)                                                                       |
| [`background_credential`](../../crates/app/src/modules/identity/mod.rs)、[`credential_is_current`](../../crates/app/src/modules/identity/mod.rs) | 已授权 actor 的请求事务 / Worker 发布事务                   | `Option<CredentialRef>` / `bool`，数据库错误 | 持久化凭据引用，不保存 Cookie；Worker 检查不会延长原凭据寿命                              | [凭据行为测试](../../crates/app/tests/sessions.rs)                                                            |

`require_session` 返回身份，不替代工单、账单等资源规则。业务应在自己的用例里验证当前访问资格，避免先检查权限、随后在另一个事务中写入造成竞态。

## 调用者拥有的数据库事务

下列入口接受 `&mut PgConnection`。传入同一个 `&mut *tx`，检查每一步的结果，最后由业务用例提交；不要先提交业务再补审计或任务。

| 公开入口                                                                                                                                                                                    | 输入 / 输出                                                       | 错误                                    | 事务责任                                                                             | 受检查用法                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| [`enroll`](../../crates/app/src/modules/organization/mod.rs)                                                                                                                                | 新用户 id → `MemberRole`                                          | `sqlx::Error`                           | 账号创建事务中加入当前企业；首位 Owner 通过组织行串行初始化                          | [注册事务测试](../../crates/app/tests/registration.rs)                                              |
| [`active_role_in`](../../crates/app/src/modules/organization/mod.rs)、[`lock_memberships`](../../crates/app/src/modules/organization/mod.rs)                                                | user id / id 列表 → 当前成员角色 / 成员记录                       | `sqlx::Error`；成员可能不存在或停用     | 写入前锁成员，再锁资源；多个成员按 id 顺序锁，维持与成员管理一致的顺序               | [成员并发测试](../../crates/app/tests/membership_policy.rs)、[成员指南](../tutorials/08-members.md) |
| [`append`](../../crates/app/src/modules/audit/mod.rs) / `Event`                                                                                                                             | actor、动作、资源和 `Source` → `()`                               | `sqlx::Error`                           | 与业务共用事务；失败回滚业务；元数据不能放任意请求 JSON 或秘密                       | [审计 HTTP 测试](../../crates/app/tests/audit.rs)、审计接入                                         |
| [`fingerprint`](../../crates/app/src/modules/idempotency/mod.rs)、[`claim`](../../crates/app/src/modules/idempotency/mod.rs)、[`complete`](../../crates/app/src/modules/idempotency/mod.rs) | `Attempt`：actor、scope、key、请求摘要 → 已有响应 / `()`          | `InvalidKey`、`Conflict`、`Unavailable` | 先授权，再 claim；已有响应直接重放；新结果 complete 后提交，错误不留下业务或占位记录 | [工单幂等实现](../../examples/tutorial-tickets/application.rs)                                      |
| [`enqueue`](../../crates/app/src/modules/jobs/mod.rs) / `NewJob`                                                                                                                            | kind、schema_version、业务 payload、尝试预算和关联信息 → Job id   | `sqlx::Error`                           | 与业务快照同一事务；kind 必须有 Worker Handler；payload 不放 token 或签名 URL        | [任务公开测试](../../crates/app/tests/jobs.rs)、任务指南                                            |
| [`on_job_outcome`](../../crates/app/src/modules/notifications/mod.rs) / `JobNotification`                                                                                                   | Job id、recipient、稳定 event_key、通用 subject 和导航目标 → `()` | `sqlx::Error`                           | 与 enqueue 注册通知意图；Jobs 在终态事务发布；目标仍检查当前访问权限                 | [通知 HTTP 测试](../../crates/app/tests/notifications.rs)、通知指南                                 |

## Files 与 Worker

| 公开入口                                                                                                                                                                                                     | 输入 / 输出                                                       | 错误或限制                                               | 调用责任                                                                                                     | 受检查用法                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| [`FileService`](../../crates/app/src/modules/files/mod.rs)：`start`、`upload_capability`、`plan_completion`、`verify_candidate`、`publish`、`download`                                                       | 上传登记 → 上传能力 → 完成计划 → 核验候选 → ready 文件 / 下载能力 | `files::Error`；对象可能缺失、变化、过期或核验失败       | 业务拥有附件归属和授权；对象 I/O 在短事务之外，核验后的发布与业务记录在同一事务                              | [对象存储集成测试](../../crates/platform/tests/object_storage.rs)、Files 接入                           |
| [`mark_deleting`](../../crates/app/src/modules/files/cleanup.rs)、[`cleanup_handler`](../../crates/app/src/modules/files/cleanup.rs)、[`cleanup_maintenance`](../../crates/app/src/modules/files/cleanup.rs) | 调用者事务的 File id / Worker 和维护注册                          | 数据库或任务错误                                         | 先在事务撤销业务可见性，再异步清理对象；API 和 Worker 使用一致的存储设置                                     | [课程源码](../../examples/tutorial-tickets/mod.rs)                                                      |
| [`Handler`](../../crates/app/src/modules/jobs/worker.rs) / [`Worker`](../../crates/app/src/modules/jobs/worker.rs)                                                                                           | `kind()` + `run(&Lease)`；连接池、Handler 列表、`WorkerPolicy`    | `Permanent`、`Transient`、`LostLease`；Worker 数据库错误 | 在 [Worker 组装点](../../apps/worker/src/main.rs)显式注册；`run_once` 便于受控测试；`run_until` 负责有界停机 | [Job 集成测试](../../crates/app/tests/jobs.rs)、恢复指南                                                |
| [`Lease`](../../crates/app/src/modules/jobs/mod.rs)：`lock_current`、`succeed`、`heartbeat`                                                                                                                  | 当前租约 + 连接 / 连接池 → `()`                                   | `JobError`                                               | 修改结果前 lock_current，业务结果和 succeed 同一提交；失去租约后不能发布                                     | [Job 集成测试](../../crates/app/tests/jobs.rs)                                                          |
| [`MailService`](../../crates/app/src/modules/mail/mod.rs)：`seal`、`open`、`send_plain_text`                                                                                                                 | 上下文绑定、受保护材料 / SMTP 文本                                | `MaterialError`、传输错误；缺少配置时 from_env 返回 None | 邮件秘密加密存储、按上下文绑定；调用者定义重试与一次性消费，不把正文写到日志                                 | [邮件材料测试](../../crates/app/tests/mail_materials.rs)、[密码恢复](../tutorials/18-password-reset.md) |
