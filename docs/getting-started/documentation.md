# 文档教程

这里是在线教程与生成参考的统一入口。全部内容与仓库源码同源：教程步骤可跟做，[API 合同](site:reference/api.md)与[配置参考](site:reference/config.md)从实现自动生成，页面页脚标注每页验收时对应的源码版本。

- 从[快速开始](quickstart.md)用一条真实请求把模板跑起来。
- [跟做教程](../tutorials/01-full-stack-request.md)按功能逐篇展开注册、会话、文档、附件、导出、成员、审计等真实链路。
- [生成参考](site:reference/api.md)提供当前 API operationId 与配置项默认值，始终与源码一致。
- 准备发布自己的站点时，阅读[发布教程站点](publish-docs.md)。

## 语言与范围

站点提供简体中文与英文两种语言，通过导航栏的语言菜单切换，同一章节互相对应；尚未翻译的章节在英文导航中不出现，也不会伪装出英文页面。搜索覆盖本站全部已发布文档与生成参考，不包含应用内数据。中文是默认阅读语言；分享链接按路径决定语言，不随设备语言自动重定向。

## 维护双语章节

新增页面必须成对提交中文与英文版本：中文源文件旁放置同名 `.en.md` 文件，并在 `docs/site.json` 中登记同一稳定 `id`、两组标题与分组标签。发布检查会校验章节配对、链接与生成参考；完整步骤见[发布教程站点](publish-docs.md)。既有尚未翻译的章节作为迁移项登记在 `docs/site.json`，由后续实现票随功能一起交付英文版本。
