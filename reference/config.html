变量默认值敏感值说明
DATABASE_URL必填是PostgreSQL connection URL. Required; never logged.
APP_BIND127.0.0.1:3000否API listener IP address and port.
RUST_LOGinfo否Structured log filter.
MIGRATION_TIMEOUT_SECS30否Migration execution deadline in seconds (1..3600).
APP_ORIGINhttp://127.0.0.1:5173否Trusted browser origin. HTTPS required except loopback development.
SESSION_ABSOLUTE_SECS604800否Absolute session lifetime in seconds (60..2592000).
SESSION_IDLE_SECS86400否Idle session lifetime in seconds (60..absolute lifetime).
S3_ENDPOINT必填否Internal S3 endpoint at its root path. Unset disables object storage.
S3_PUBLIC_ENDPOINT必填否Browser-accessible S3 origin. Defaults to S3_ENDPOINT; HTTPS except loopback.
S3_BUCKETsaas-files否Dedicated private application bucket.
S3_REGIONus-east-1否S3 signing region.
S3_ACCESS_KEY必填是Explicit S3 access key; required when S3_ENDPOINT is set.
S3_SECRET_KEY必填是Explicit S3 secret; required when enabled, never logged.
FILE_MAX_BYTES20971520否File byte limit, verified again on the final object (1..104857600).
UPLOAD_SESSION_SECS900否Upload resource/signing lifetime in seconds (1..3600).
DOWNLOAD_URL_SECS60否Download capability lifetime in seconds (1..300). Revocation blocks new signing.
WORKER_BIND127.0.0.1:3001否Worker health listener IP address and port.
JOB_LEASE_SECS60否Job lease lifetime (5..3600 seconds).
JOB_HEARTBEAT_SECS20否Lease renewal interval (1..half the lease seconds).
JOB_SHUTDOWN_SECS10否Maximum active-work drain before process exit (1..60 seconds).
JOB_MAINTENANCE_SECS30否Interval for bounded maintenance scheduling (1..3600 seconds).
EXPORT_JOB_MAX_ATTEMPTS5否Finite attempt budget per export execution batch (1..20).
EXPORT_MAX_ATTACHMENTS100否Maximum attachments in one document export (0..1000).
EXPORT_MAX_INPUT_BYTES268435456否Maximum snapshot Markdown and attachment bytes (1..1073741824).
EXPORT_MAX_OUTPUT_BYTES285212672否Maximum ZIP extent, including headers and central directory (1024..1107296256).
EXPORT_RETENTION_SECS86400否Export and snapshot lifetime (60..604800 seconds).
EXPORT_TIMEOUT_SECS120否Entire export execution budget (1..600 seconds), with cooperative blocking cancellation.
