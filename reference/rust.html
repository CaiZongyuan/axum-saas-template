Rust 公共接入地图 ​

这页面向正在编写自己业务模块的后端开发者。HTTP DTO 在 API 参考 查阅；Rust 函数的完整签名和内部限制以链接源码为准。先完成 新增后端模块，再按需要接入下表。

saas_app 提供 SaaS Core 与 HTTP 边界，saas_platform 提供配置和基础设施适配。业务模块调用这些公开能力；API 与 Worker 在应用侧显式组装。当前企业模型是单个 Organization，不支持把不同客户的数据放进同一数据库后自动隔离。

HTTP 与身份 ​

公开入口调用上下文返回值或错误责任与限制受检查用法
compose_routes_with_options / CoreOptions应用启动：连接池、认证配置、业务 Router、合并 OpenAPIAxum Router提供 Core 路由、request_id、限流和统一 fallback；先完成业务 state，再 merge第一阶段模块、HTTP 健康测试
BoundedJson、ApiQuery、ApiPath经过 Core request_context 的 Handler；JSON extractor 放最后反序列化后的 DTO；失败为公开 Response只负责协议读取；长度和业务规则继续由 Domain 验证身份 HTTP 测试
require_session连接池、AuthSettings、请求头、RequestId、是否 mutationResult<CurrentSession, Response>mutation 校验 Origin/CSRF；显式 Authorization 不会退回 Cookie；写事务仍须重新锁定有效成员Session HTTP 测试、Session 接入
require_read只读接口，额外传入业务注册的 scopeResult<ReadActor, Response>Bearer 存在时优先；检查凭据、成员和 scope 后，业务继续检查资源权限API Key HTTP 测试、API Key 接入
KeyScope、core_scopesAPI 应用组装scope 声明 / Core scope 列表把业务只读 scope 添加到 CoreOptions；scope 不等于资源授权API 组装点
background_credential、credential_is_current已授权 actor 的请求事务 / Worker 发布事务Option<CredentialRef> / bool，数据库错误持久化凭据引用，不保存 Cookie；Worker 检查不会延长原凭据寿命凭据行为测试

require_session 返回身份，不替代工单、账单等资源规则。业务应在自己的用例里验证当前访问资格，避免先检查权限、随后在另一个事务中写入造成竞态。

调用者拥有的数据库事务 ​

下列入口接受 &mut PgConnection。传入同一个 &mut *tx，检查每一步的结果，最后由业务用例提交；不要先提交业务再补审计或任务。

公开入口输入 / 输出错误事务责任受检查用法
enroll新用户 id → MemberRolesqlx::Error账号创建事务中加入当前企业；首位 Owner 通过组织行串行初始化注册事务测试
active_role_in、lock_membershipsuser id / id 列表 → 当前成员角色 / 成员记录sqlx::Error；成员可能不存在或停用写入前锁成员，再锁资源；多个成员按 id 顺序锁，维持与成员管理一致的顺序成员并发测试、成员指南
append / Eventactor、动作、资源和 Source → ()sqlx::Error与业务共用事务；失败回滚业务；元数据不能放任意请求 JSON 或秘密审计 HTTP 测试、审计接入
fingerprint、claim、completeAttempt：actor、scope、key、请求摘要 → 已有响应 / ()InvalidKey、Conflict、Unavailable先授权，再 claim；已有响应直接重放；新结果 complete 后提交，错误不留下业务或占位记录工单幂等实现
enqueue / NewJobkind、schema_version、业务 payload、尝试预算和关联信息 → Job idsqlx::Error与业务快照同一事务；kind 必须有 Worker Handler；payload 不放 token 或签名 URL任务公开测试、任务指南
on_job_outcome / JobNotificationJob id、recipient、稳定 event_key、通用 subject 和导航目标 → ()sqlx::Error与 enqueue 注册通知意图；Jobs 在终态事务发布；目标仍检查当前访问权限通知 HTTP 测试、通知指南

Files 与 Worker ​

公开入口输入 / 输出错误或限制调用责任受检查用法
FileService：start、upload_capability、plan_completion、verify_candidate、publish、download上传登记 → 上传能力 → 完成计划 → 核验候选 → ready 文件 / 下载能力files::Error；对象可能缺失、变化、过期或核验失败业务拥有附件归属和授权；对象 I/O 在短事务之外，核验后的发布与业务记录在同一事务对象存储集成测试、Files 接入
mark_deleting、cleanup_handler、cleanup_maintenance调用者事务的 File id / Worker 和维护注册数据库或任务错误先在事务撤销业务可见性，再异步清理对象；API 和 Worker 使用一致的存储设置课程源码
Handler / Workerkind() + run(&Lease)；连接池、Handler 列表、WorkerPolicyPermanent、Transient、LostLease；Worker 数据库错误在 Worker 组装点显式注册；run_once 便于受控测试；run_until 负责有界停机Job 集成测试、恢复指南
Lease：lock_current、succeed、heartbeat当前租约 + 连接 / 连接池 → ()JobError修改结果前 lock_current，业务结果和 succeed 同一提交；失去租约后不能发布Job 集成测试
MailService：seal、open、send_plain_text上下文绑定、受保护材料 / SMTP 文本MaterialError、传输错误；缺少配置时 from_env 返回 None邮件秘密加密存储、按上下文绑定；调用者定义重试与一次性消费，不把正文写到日志邮件材料测试、密码恢复

Platform 与验证入口 ​

公开入口返回 / 边界使用指南
Settings / from_envResult<Settings, ConfigError>；启动校验失败应退出生成服务端配置、变量来源
Cache：get、put、removeLookup、CacheUnavailable；共享 deadline，不保证 Redis 可用缓存接入、真实缓存测试
RateLimiterHTTP 请求预算；API 组装时共享实例限流策略、限流 HTTP 测试
init / TelemetryGuard启动遥测；guard 在有界停机时 shutdown日志与追踪、关闭测试

源码签名不是事务提交证明。编写自己的 HTTP 行为测试，对拒绝、重放、回滚和租约失效验证可观察结果。工单用例源码与 课程 HTTP 测试展示自己业务的接入；模板所有权与移除边界见 模块关系。

完整参考业务的接入指南：幂等与版本、Files、Jobs、恢复、删除、通知、审计、API Key、缓存、追踪。这个参考业务阅读入口随知识库移除；共享能力指南继续保留。
