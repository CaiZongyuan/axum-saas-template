A Rust + React foundation for your next SaaS

A working application to learn from and to build on. Registration, sessions, members, rate limits, jobs, deployment and backup are not roadmap promises — they are capabilities you can start, verify and replace today.

DocumentationGitHub repository

How you use it

1

Start the full stack

After cloning, one just dev brings up the API, the worker, the web app, PostgreSQL, Redis, RustFS and Mailpit.

2

Send the first full-stack request

Follow the tutorials from a real request; every chapter maps to runnable commands and test entries.

3

Compose or remove the example

Remove the reference example block by block per the ownership manifest; Core keeps running, with static checks guarding the boundaries.

4

Deploy, back up, restore

Single-machine compose production with degradation verification, plus backup archives and isolated-environment restore drills.

Real capabilities

Everything below is delivered, each with tutorial chapters, automated tests and gates — not planned items. The item-by-item ledger lives in v1 capability coverage and acceptance.

Registration, sign-in and sessions

Transactional registration and sign-in, session invalidation and multi-device management, verified against API tests and real browser journeys.

Members and the last owner

Role changes and deactivation revoke sessions immediately, and last-owner protection keeps the organization reachable.

Password reset and reliable email

Registration and reset mail lands in Mailpit in the development stack; production switches to a real SMTP server.

Rate limits and degradation

Redis-backed rate limits degrade conservatively: when the cache is down the service keeps answering, and the system page shows real status.

Electron desktop shell

The same web pages enter a secure desktop shell; IPC contract tests and the desktop smoke run in CI.

Single-machine production

A compose production stack with degradation verification; the public tutorial covers the whole path from certificates to fallback.

Backup and restore drills

Backup archives carry no secrets; a restore into an isolated environment verifies documents, attachments and jobs.

The reference example: a personal knowledge base

A removable reference business that shows how business constraints, concurrency and resource authorization compose on top of Core; the boundaries and the removal steps live in Compose and remove reference examples.

Your first Markdown document

Document CRUD with safe body rendering.

Title search and safe preview

Title search, pagination and a preview that never executes scripts.

Explicit saves and version conflicts

Concurrent saves trigger a 409 with an understandable conflict flow.

Shared knowledge bases and grants

Reader/Editor grants, revocations and permission inheritance.

RustFS attachments

Attachment upload and download over real object storage, hashing and browser CORS.

Exports and jobs

ZIP exports run as PostgreSQL Jobs; failures are retried by an administrator.

API keys and resource permissions

Issue a key that reads the knowledge documents it is permitted to read, with the scope verifiable.

Start with the documentation

The tutorials evolve in lockstep with the source: every chapter can be followed, verified, and replaced wholesale with your own business.
